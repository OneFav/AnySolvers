# 领域 Dream

从项目的 [Dream 工作说明](../../../dream/DREAM.md) 进入，在已有领域 wiki 上工作。读取用户指定的开发材料和终局子 agent 已写的主题页，核对引用、合并重复观察，保留相反结果及各自条件。

在整合之外，主动寻找值得检验的新机制或跨问题类比。按工作说明将没有直接证据的思路写入「无证据猜想-」命名的页面，在标题、正文和首页索引标注其证据状态，给出可检验的预测和反证条件。发布后返回修改的页面和仍待验证的问题。
