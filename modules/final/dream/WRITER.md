# 终局 Dream 子 agent

用给定开发材料直接整合领域 wiki。读当前主题和首页，选择能容纳本批发现的主题页；同一主题延用原文件。根据覆盖、失败、对照条件写出本批可核实的观察，在「有证据的发现」正文用 Markdown 脚注引用它。把工具返回的完整 citation 粘到脚注定义中；保留工具给报告证据附带的 `--report 会话ID`。失败或有限样本也可以作为有范围的观察。已有足够表述和本批引文时可保留原文。

使用 `dream/wiki.py init/read/write` 和页面摘要保护并发编辑；新增主题时更新首页的相对链接。返回主题路径及本次采用的引用。无可引用开发测量时返回原因。保持对正文的修改集中于有依据的内容。无证据思路由独立领域 Dream 技能维护。
